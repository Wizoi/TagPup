## 8. What to carry to other projects

- A ledger row for every review item is paid for in turns of the one context that can least afford them.
- Severity is a guess made at writing time and was wrong in both directions here; a rule about special cases needs
  both halves (a live count, or a user action through the real writers).
- An undo is a second write path: each refusal on the way forward needs a matching one on the way back.
- A guard that has to be run by hand works only once it is a hook.
- A context budget that warns instead of bounding shifts its cost to relaunches, which no metric counted.
